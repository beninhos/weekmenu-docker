Tekst uitlezen (Cloud Vision)

Leest de tekst van receptpagina's letterlijk uit, vóór Gemini er structuur van maakt. Nodig voor het inlezen van kookboeken: zonder deze stap worden breuken als ½ verkeerd gelezen. Gratis tot 1.000 pagina's per maand.

✓ API key geconfigureerd

Maak een API key aan in de Google Cloud Console en beperk hem tot de Cloud Vision API. Zet de API zelf ook aan via de API-bibliotheek. Cloud Vision vraagt een gekoppelde betaalmethode, ook al blijven de eerste 1.000 pagina's per maand gratis.

Recept opmaken (Gemini)

Herkent recepten uit een link of losse foto's, en maakt bij het inlezen van een heel kookboek een recept van de tekst die Cloud Vision hierboven uitleest. Gratis tot 250 verzoeken per dag.

✓ API key geconfigureerd

Voer je Gemini API key in. Je kunt er gratis een aanmaken via Google AI Studio.
